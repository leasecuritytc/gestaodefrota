# assets/icons

Reservado para os ícones oficiais da plataforma (favicon, logo RodaCoop em formato de ícone, símbolos usados na futura interface).

Nenhum arquivo de ícone foi recebido ainda — esta pasta existe para já deixar o lugar certo definido, evitando que um ícone futuro seja salvo solto na raiz do projeto ou em pasta errada.

Quando o logo oficial da RodaCoop (ou favicon) for enviado, ele entra aqui, por exemplo:
- `rodacoop-logo.svg` — logo vetorial (preferível, escala sem perda)
- `favicon.ico` / `favicon.png` — ícone de aba do navegador
