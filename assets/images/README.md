# assets/images

Imagens de identidade visual da plataforma (não são dados do banco — ficam versionadas aqui, fora do código do backend).

- `rodacoop-fundo-plataforma.jpg` — arte de fundo enviada para uso na plataforma (ex.: tela de login, cabeçalho do dashboard). Enviada em 24/11/2026.
  **Importante:** até agora este projeto só tem o backend (API) pronto — ainda não existe uma tela/frontend para aplicar esta imagem como fundo. Ela já está salva e organizada aqui para quando o frontend for construído; nada foi perdido nem ficou solto em conversa.

Ao adicionar uma nova imagem, use nomes descritivos em minúsculas com hífen (`algo-assim.jpg`), nunca o nome genérico que a imagem chega (tipo `image.jpg`), para manter o padrão profissional do repositório.
